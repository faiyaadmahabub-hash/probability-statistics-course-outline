# Probability and Statistics Course Outline

A curriculum plan prepared during the Kidocode internship for beginner and intermediate probability and statistics lessons.

## Files

- `probability & statistics Course Outline.docx.pdf`: course outline covering probability, sets, event rules, descriptive and inferential statistics, counting principles, permutations and combinations.
- `Probability and Statistics Course Outline.xlsx`: editable lesson planning workbook, with five beginner modules and 25 lessons. Task, task type and description columns are available for further development.

## Use

Read the PDF in a PDF viewer. Open the workbook in Excel or LibreOffice to plan exercises and lesson tasks.

## Current status

This is a curriculum draft. The workbook places counting methods in the beginner track while the PDF places them in the intermediate track; reconcile that placement before delivering the course. The lesson task columns are not yet filled in.
